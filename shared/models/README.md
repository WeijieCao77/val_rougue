# Character model source

`soldier.glb`, `enemy.glb`, and `hazmat.glb` are characters from Quaternius's [Toon Shooter Game Kit](https://quaternius.com/packs/toonshootergamekit.html). The pack page lists the characters and animations as free for commercial game use and labels the pack CC0. These assets are used as part of this game's battle scene. The three files retain their original kit names for traceability. For any later asset replacement, check the creator's [current license page](https://quaternius.com/license.html) as well.
