# Character model source

`soldier.glb`, `enemy.glb`, and `hazmat.glb` are the retired battle characters from Quaternius's [Toon Shooter Game Kit](https://quaternius.com/packs/toonshootergamekit.html). The pack page lists the characters and animations as free for commercial game use and labels the pack CC0. The three files retain their original kit names for historical traceability. For any later asset replacement, check the creator's [current license page](https://quaternius.com/license.html) as well.

The active battle characters are `operative-swat.gltf`, `operative-adventurer.gltf`, `operative-punk.gltf`, and `operative-spacesuit.gltf` from Quaternius's [Ultimate Modular Men Pack](https://quaternius.com/packs/ultimatemodularcharacters.html). Its included license is preserved in `QUATERNIUS_MODULAR_CC0.txt` and states CC0 1.0. These glTF files contain embedded buffers and were downloaded from the pack's official download folder. The older Toon Shooter GLBs remain in the repository for historical traceability but are no longer loaded in battle.
