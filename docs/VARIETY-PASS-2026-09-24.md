# 多样性改造（2026-09-24）：对手、卡牌、状态图标、商店

起因是用户试玩反馈：每回合步骤差不多，对手“只会打两下”，外观都一样；状态不够醒目；商店一打开就是三张牌，没有游戏感。用户要求多参考《杀戮尖塔》，以及《炉石传说》《皇室战争》等卡牌游戏的多样性。两版 Demo 一起改。

## 对手（两版）

| 类型 | 外观 | 打法／特性 |
| --- | --- | --- |
| 新秀步枪组 | 步枪手 | 基础攻击，偶尔强化火力 |
| 远点狙击手 | 兜帽、长狙 | 先瞄准，下回合重狙；新 Demo 用闪光、瓦 Demo 用压制可以打断，只剩 1/3 伤害 |
| 突破手双枪 | 莫西干头、双冲锋枪 | 多段攻击；生命首次过半时获得火力（背水一战） |
| 哨位架枪组 | 防暴盾、重盔 | 开局自带布防；每次被攻击命中反击（交叉火力），多段攻击要慎用 |
| 烟雾控场手 | 防毒面具、无人机 | 压制、塞入异常牌、给你易伤 |
| 前哨侦察兵 | 天线、弓 | 你每打出一张技能牌（瓦 Demo：不造成伤害的牌），它获得火力 |
| 王牌突击手（强敌） | 长风衣 | 每回合结束火力 +1，逼你速攻 |
| 战术指挥官（强敌） | 军官帽、平板 | 固定节奏：强化、连射、清除负面并大额布防、重击 |
| 三幕 Boss | 各不相同 | 第一幕：你每打出一定张数的牌，它就获得火力和布防（控制节奏）；第二幕：固定的“经济局／全起”节奏；第三幕：生命过半进入第二阶段，换成全新打法 |

每场普通战（第 3 站起）和强敌战会随机分配一种战场：狭窄走廊、开阔长廊、烟雾弥漫／火力压制、高点优势、加时赛、经济局，对双方同时生效。

瓦 Demo 的教学关旧对手（E01–B01）保持原样，以保证冻结的回放样本仍能精确重放；赛季模式使用新对手。瓦 Demo 赛季存档键已轮换，旧的进行中存档不能继续。

## 卡牌（参考杀戮尖塔的流派设计）

- **燃烧**：每回合在对手行动前扣血，并且无视布防；配套有翻倍燃烧层数的牌、把燃烧一次引爆的牌，以及每回合自动点火的能力。
- **部署**：哨戒炮在回合结束时自动开火，屏障无人机在回合结束时提供布防；另有让所有炮台立即开火一次的集火牌。
- **连击**：本回合已打出其他牌时追加效果；配套 0 费飞刀（临时牌）、飞刀增伤能力，以及“每回合第 3 张起攻击增伤”的能力。
- **布防反击**：以布防造成伤害、保留牌、消耗时获得布防等。
- **过载爆发**：本回合打出大伤害或大额布防，代价是下回合少行动点。
- **易伤处决**：对手有易伤时额外伤害；本场火力（全场每段攻击伤害提高）。
- **发现**（仅新 Demo，参考炉石）：从 3 张随机牌中选 1 张加入手牌，本回合 0 费，打出后消耗。瓦 Demo 暂不加入发现，因为 PvP 需要为对手隐藏选项。

新 Demo 新增 33 张流派牌。奖励的 3 张牌尽量来自不同标签，每家补给店有一件半价商品。瓦 Demo 把每赛区 10 张原本效果很平淡的赛区战术牌改成流派牌（共 40 张），赛季奖励保证至少有 1 张流派牌。PvP 对战引擎同步支持这些效果。

**顺带修复**：PvP 原来只接受选手牌和隐患牌，历史构筑里只要有赛区战术牌就会被拒绝，现在已修复。

## 界面

- 所有状态改为图标＋数字徽章，直接贴在人物立绘上，悬停可看规则。
- 卡牌和意图文字里的关键词加粗、上色并配图标。
- 敌人特性和本场战场有单独标签。
- 已部署的炮台和屏障显示在我方人物身上。
- 11 种敌人各有不同的 3D 轮廓，由程序化低多边形生成，原创、无外部素材。
- 商店改成场景：新 Demo 是军需官“老周”的战术补给站，瓦 Demo 是转会经纪人“老K”的转会市场。经纪人会根据你的资金说不同的台词，商品挂价签，服务移到柜台区，离开按钮单独放置。

## 平衡（自动试玩机器人，不等于真人手感）

`tools/playtest-new-demo.mjs`、`tools/playtest-wa.mjs`：机器人每回合搜索最佳出牌顺序，并且能看到抽牌顺序，比真人占便宜。

- 新 Demo 三幕全通：约 25–35%，第三幕 Boss 仍是主要难点。
- 瓦 Demo 三幕全通：约 11/20（改动前基线约 7/20）。美洲和 EMEA 明显更容易，中国和太平洋偏难；这种赛区差距在改动前就存在，需要单独处理。
