# 存档码（2026-09-28）

一个永久的个人「存档码」同时是账号和云存档：登峰赛季（/wa/）、战术试炼（/new/）、好友 PvP（/pvp/）都用它。换手机、换电脑、清除浏览器数据后输入存档码即可找回，不需要两台设备同时在线。取代了面向玩家的「进度同步（10 分钟 6 位码）」。

## 一、格式与安全
- 12 位，字母表 `ABCDEFGHJKMNPQRSTUVWXYZ23456789`（31 个无歧义字符，无 0/1/I/L/O），约 59 位随机量；显示为 `XXXX-XXXX-XXXX`。输入不分大小写，可带横线、空格。
- 服务端只存 `HMAC-SHA256(pepper, 码)`（`save_codes` 表）。pepper 取环境变量 `SAVE_CODE_PEPPER`，没有就随机生成存进 `meta` 表 `save_code_pepper`。存档码不写日志，后台也查不到原码。
- 防暴力（内存，单实例）：同一 IP（加盐哈希）15 分钟内输错 10 次 → 锁 15 分钟，锁定期间输对也不行；全站 1 小时内错 500 次 → 所有存档码登录锁 15 分钟。错误只提示「存档码不正确」。每 IP 每小时最多新建 20 个存档码；每个账号每小时最多换码 5 次。
- 粘贴旧版 64 位 PvP 账号凭证到存档码输入框也能登录（同一个账号，错误同样计入锁定）。

## 二、账号与数据
- 复用 PvP 账号（`accounts` 表）。每台用存档码登录的设备得到自己的 Bearer 令牌（`account_tokens` 表，每账号保留最近 50 个），PvP 不用改。
- 每个账号每个版本（wa/new）一份进度：沿用 `sync_links` 的行、打包和冲突规则（版本号 + 保存时间，较新的胜出，另一份存为单槽备份）。`account_sync` 把账号和进度行对应起来；属于账号的进度行不会被 180 天闲置清理删除。
- 接口 `/api/save/ensure|login|sync|restore|newcode|logout`（见 `online/save-api.mjs` 文件头）。旧 `/api/sync/*` 保留，缓存了旧页面的设备还能用。
- 自动保存节奏不变：最多每 30 秒一次；幕结束、局结束、页面隐藏时立即上传。打开游戏时如果云端较新就载入并提示。
- 进度包不再包含 PvP 令牌 `wa-online-token`（账号由存档码登录决定）。「真实进度」不含成就对象（首次打开页面就会写入一个空的）。

## 三、迁移（谁都不丢进度）
1. **只有 PvP 令牌的设备**：打开游戏时自动补上存档码，令牌不变，账号不变。
2. **用旧同步码连接过的设备**：设备把旧同步凭据交给 `ensure`。
   - 旧同步行还没归属任何账号 → 并入这台设备的账号（没有账号就新建），进度和版本号原样保留。
   - 两台连接的设备各有不同的 PvP 账号：**先申请存档码的那台设备的账号胜出**，旧同步行归它；另一台设备随后申请时，旧同步行已属于那个账号，于是这台设备并入该账号、拿到新令牌，原来的令牌存进本机 `wa-online-token-previous`。原账号在服务器上保留不动，在 PvP「高级：旧版账号凭证」里可以一键切换回去或导出。选这个规则是因为进度（同步行）只能属于一个账号，而先申请的设备通常就是玩家主力设备；另一个账号的 PvP 构筑也不会丢。
3. **两者都没有的设备**：出现真实进度（开始第一局）时静默创建账号和存档码，从此自动备份；弹提示并在「存档码」按钮上标「新」，面板里醒目提示「请截图或抄下保存」。
   - 与原计划的差别：没有进度的设备打开面板时**不**自动建号，而是先显示「已有存档码？在这里输入」，再给「生成我的存档码」按钮。否则清空浏览器后想找回进度的玩家会先看到一个新的空存档码，容易误会。

## 四、登录、换码、退出
- 在已有进度的设备上登录别的存档码：采用存档码里的进度，本机进度存为备份（内容相同则不覆盖备份），提示可在「存档码」里恢复。另一个版本在下次打开时同样处理。
- 设备只在生成或输入过存档码时知道原码；通过旧令牌或旧同步链接迁移过来的设备看不到原码，可以「生成新的存档码」（旧码作废，已登录的设备不受影响）。
- 「退出这个存档码」：本机进度保留，删除本机的令牌和存档码，服务器上删除这台设备的令牌；之后不会再自动建号，直到玩家重新登录或生成。
- 后台 `/admin/`「存档码」一栏：按 16 位账号 ID 查看（是否已有存档码、各版本进度版本号与大小、设备数），并可「补发新存档码」（旧码立即失效，新码只显示一次）。玩家在面板底部能看到自己的账号 ID。没有做「按存档码后四位查找」：那需要明文保存后四位，会削弱哈希。
