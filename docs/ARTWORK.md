- 72 张选手牌：71 张来自对应 VLR 选手资料页，glacier 使用狼队官方官宣在新浪转载页中的照片。使用审核过的选手 ID 对应资料页，再匹配页面姓名，不用搜索结果中的同名人物替代。

## DeepSeek 实际参与与验收修改

DeepSeek v4 Pro 负责照片采集脚本及修订、特殊牌 SVG 初稿、对手三方向提案、枪械草稿、真实皮肤候选筛选、能量 CSS 初稿及最终静态审查。调用记录保存在不提交的 reports/art/ 中。

主代理执行检索脚本、核对来源与文件、整合界面和验收。拒收了过于简陋的矢量枪械草稿，改用实际枪械皮肤图；废弃的人形方案没有进入游戏。修正了采集脚本中的字段、返回值和图片校验问题，识别并替换 glacier 的默认剪影；修正 Boss 图的幕次错配、枪口朝向、双枪被截半以及手机旧样式将头像压至 34px 的问题。DeepSeek 的界面模块初稿只返回文件名，未作为有效实现采用；最终展示模块由主代理完成。

最终静态审查中的“来源链接可能为空”不符合已核对数据，未当作已证实缺陷；特殊牌裁切建议结合实际界面检查处理，没有据此更改玩法。

## 验证与维护

- 55 项 Node 测试通过，包含 72 张不同照片、79 张卡与 21 个对手素材覆盖、来源映射、图片格式、静态服务边界以及原游戏回放。
- 72 张照片经图片解码检查；下载的枪械图逐一与实际 API 候选 URL 匹配。无运行时第三方图像请求，素材本地随游戏发布。
- 浏览器实际操作 Kai：敌方防线 28 → 21，行动点 3 → 2；悬停解释、出牌目标和刷新继续仍可使用。
- 检查桌面和 390 × 844 手机尺寸，修正照片高度冲突；页面宽度为 390，无横向溢出。没有修改用户原来 4177 入口的存档。
- 同幕或跨幕共用战术原型图片属于本轮明确复用，不是为 21 个对手分别画了 21 张图；当前没有枪械攻击动画和音效。

数据位于 assets/player-sources.json、assets/weapon-sources.json、assets/opponent-sources.json。修改素材映射后运行 npm run build，生成 art-data.js、art-gallery.html、app.js、style.css。不要直接改生成文件。
