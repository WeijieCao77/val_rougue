# 新demo：插图与出牌反馈验收

本轮仅供本地 `http://127.0.0.1:4180/new/` 试玩，未发布生产环境。规则与牌池保持原样，改进表现和操作。

## 已实现

- 75张战术牌、3张状态牌、21支敌方队伍、4支我方队伍及12件遗物均有原创 SVG 插图。采用统一战术人物与场景模板组合，属于原型美术，并非每张独立手绘或官方素材。
- 桌面双方面板、底部手牌、卡框与悬停提示；支持点击选牌、键盘出牌及桌面拖拽。手机使用点击出牌与横向手牌滚动。
- 攻击弹道、伤害数字、布防、烟雾、闪光、姿态切换、抽牌、弃牌与消耗反馈；出牌时使用实际卡面飞行。支持减少动态效果的系统偏好。
- 抽牌堆、弃牌堆与消耗堆可查看。抽牌堆展示排序副本，不泄露实际抽取顺序。
- 动画期间阻止重复结算；非法拖放、取消拖拽、牌堆弹窗与离开战斗均有处理。

## 分工与验证

主要插图、特效、界面实现及浏览器测试初稿、返修由官方 API 的 `deepseek-v4-pro` 完成。主代理负责集成、实际运行和视觉验收；修正测试前提错误、术语与 SVG 属性错误。调用结果、用量及浏览器截图保存在本机被忽略的 `reports/dual-demo/`，游戏运行不调用模型。

- `npm run build` 成功；`npm test`：109项通过。
- 桌面与390像素手机浏览器交互：10项通过，涵盖出牌、烟闪布防、抽弃消耗、重复操作保护、拖拽及取消、移动端和减少动态效果。
- 115个插图输出通过 XML 解析与无效内容检查。
- 补验最后一击进入奖励页、动画层清理、弹窗阻止战斗快捷键、姿态切换，未记录 JavaScript 错误。
- 战斗用固定测试状态验证表现与流程；这些结果不代表数值平衡已完成。
- 生产隔离测试包含新增资源路径，生产环境继续拒绝 `/new/`。

试玩重点：选牌与拖出是否自然、攻击和布防是否容易看清、插图风格是否符合方向。美术精细度与动画节奏仍可在用户试玩后迭代。
