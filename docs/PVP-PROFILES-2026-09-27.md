# 玩家昵称、头像与正式名称

2026-09-27：登峰赛季 PvP 首页新增玩家身份入口；首次进入提示设置昵称。昵称为 2–16 个 Unicode 字符，双方无需昵称唯一。提供六款原创猪之家战术头像；支持自定义图片上传和恢复默认头像。

参考本地 val_player/match-rating 的 AvatarEditor.tsx、avatarImage.ts：按实际图片内容识别格式、居中方形裁剪、压缩预览、具体错误提示。区别：本作 PvP 需要对手可见，因此压缩头像保存到服务端，而非只存本地。

客户端仅接受静态 PNG/JPEG/WebP（8 MB、8192 边长、4000 万像素），转成 128×128 JPEG。服务器通过 sharp 再次解码、限制像素、裁剪和去元数据。头像写入 SQLite 账号 extra 字段；不修改现有 schema 或持久卷。房间与对战只返回昵称、默认头像 id 或带版本的公开头像路径，不返回原始图片、凭据或元数据。只保留当前头像；账号凭证恢复也恢复昵称及头像。

接口：PATCH /api/account/profile（认证、同源、限流）；GET /api/avatars/:accountId（压缩公开头像）；GET /api/account 返回资料。加入房间时复制身份，修改资料同步当前房间，轮询更新双方 HUD。

正式名称：登峰赛季、战术试炼。玩家页面标题、封面、版本入口及更新日志标签统一；内部路由、存档键和冻结版本代号保留。

验收：首次设置、默认选择、图片上传、首页身份、手机390×844及电脑1280×720牌桌显示。新增API校验、房间身份同步、数据库重启保存、去元数据测试；402项测试通过。战斗画面验收使用本地测试房间，不改生产玩家数据。
