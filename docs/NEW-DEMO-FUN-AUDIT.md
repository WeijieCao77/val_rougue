# 新 Demo：首轮可玩性诊断（2026-09-23）

产品定位：保留《杀戮尖塔》式的路线、抽牌、构筑与回合资源抉择，改用战术赛季题材。题材差异不能代替游戏性。以下把可核查的现状与尚待玩家测试的判断分开。

| 现状（改动前） | 为什么可能不好玩（待试玩验证） | 本轮处理 |
| --- | --- | --- |
| 四队、路线、种子、姿态、状态与卡牌分类同时出现在第一局 | 新手还没感受到出牌收益，就要理解太多名词 | 首页一句话目标、突破队入门标记、首次地图/战斗短提示、随时可重看的玩法指南 |
| 部分 2–3 费牌只是更大的伤害/布防数字 | 抽到高费牌后没有组合或时机决策 | 七张牌改为破防、压制、烟闪联动、抽牌或攻守兼顾；基础低费牌仍简明 |
| 未知事件只有三种，地图的保证节点在固定行，对手按固定脚本循环 | 换种子后地图外形不同，赛季节奏和比赛仍显重复 | 保证事件/补给/强敌的行数按种子变化，事件池增至六种，对手已有意图按种子洗牌并继续提前展示 |
| 手机牌面继承了 `white-space: nowrap`，新 Demo 又覆盖了横向牌列 | 效果在牌框内被切掉，手牌无法浏览，构筑价值难以理解 | 横向可滑动牌列、可完整换行的效果文字、保留拖牌和点牌操作 |
| 现有细长人物在手机战斗区难以辨认 | 攻防反馈缺少“我方队伍 vs 对手”的角色感 | 共享 3D 战场改用原创低多边形像素 Q 版模型，玩家/对手配色与轮廓不同 |

本轮仍不能证明“已经变得好玩”。剩下的关键风险是：不少牌之间只有小幅数值差异；单敌人战斗缺少目标优先级；三个赛段仍可能过长；事件与遗物的协同深度还有限。下一轮应固定几组种子做完整首幕试玩，记录每场是否有至少一次有后果的抉择，以及玩家能否不看说明讲清卡牌、状态和路线。按结果再改卡组分布、对手机制或赛程长度，避免凭空加随机概率。

参考原则来自 [Mega Crit 的《Slay the Spire》介绍](https://store.steampowered.com/app/646570/Slay_the_Spire/)：动态构筑、不同路线和不同对手共同构成重复游玩的变化。本项目上述具体牌效与概率均为自行调整，非原作数值。
