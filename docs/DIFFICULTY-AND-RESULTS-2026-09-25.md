# 第一幕减压与随机结果反馈（2026-09-25）

对应真人反馈：“两局都没打到第一幕 Boss，难度稍微降一点”；“随机训练一张牌的事件没告诉我训练了哪张”。

## 一、随机结果反馈（两版）

凡是玩家没有亲自选定的效果，引擎都在本次操作的状态里记一份结构化结果 `state.lastResult = {title, entries:[{kind, text, random, id?, from?, diff?}]}`；每次操作开始时清空。界面在操作结算后读它：

- 战斗外：弹出结果窗（`shared/result-summary.js`，样式在 `shared/run-meta.css`），逐条写明卡牌／装备名称，升级写“前 → 后”，例如“已训练：Kai（伤害 7 → 10）”“已升级：快速架点（获得 3 → 5 点布防）”“加入俱乐部隐患：磨合不足（……）”。“知道了”、Esc／Enter 或点空白处关闭。
- 战斗内（如“本场随机升级 1 张手牌”）：只在提示条写一行，不打断出牌。
- 只有含随机条目的操作才弹窗；纯确定的选择（付钱、回血）不弹。补给箱的金币和装备已在箱子房间里显示，不重复弹窗（条目带 `inline`）。

覆盖范围：

## 二、难度

真人两局都没到第一幕 Boss。原先的目标是智能机器人第一幕通关 45–60%，但机器人每回合搜索整条出牌顺序、并能看到抽牌顺序，远比真人强。本次新目标（难度 0、基础解锁池、智能机器人）：首战失血 3–6，第一幕普通战 4–8，到达第一幕 Boss ≥ 90%，第一幕通关 70–80%，三幕通关 25–35%；另加“粗心玩家”代理：`casual` 策略到达第一幕 Boss ≥ 50%。

### 新的试玩策略

两个试玩脚本都支持 `--policies smart,naive,casual`，并输出“milestones”表（首战失血、第一幕普通战／强敌／Boss 失血、到达 Boss、各幕通关）。

- `smart`：原有机器人（整回合搜索，能看到抽牌顺序）。
- `naive`：按手牌顺序能打就打，奖励总拿第一张；新 Demo 不用姿态，不用补给品。它是下限，不是真人代理。
- `casual`（新）：每次只往前看一张牌（这张牌对即将到来的对手回合有什么影响），不规划整回合、不看抽牌顺序；新 Demo 也会考虑切换姿态；奖励在“不比牌组平均差”的牌里随机拿；路线在智能机器人的偏好上加随机扰动；只在危险时用补给品。

### 改了什么

只动对手数值，主要是第一幕前半段；难度 1–10 仍叠加在上面。

新 Demo（本地单机，无重放约束）：

- `EARLY_EASE`（`new-demo/content.js`，引擎按本场所在层数套用）：第一幕 1–4 层（弱敌层）生命 ×0.85、伤害 ×0.8；5–8 层普通战 ×0.9／×0.88；8 层以内强敌 ×0.75／×0.7；9–15 层普通战 ×0.95／×0.93、强敌 ×0.85／×0.82。

### 读数与遗留

- 两版智能机器人的首战、普通战、第一幕通关都落在目标内；新 Demo 到达 Boss 95%，瓦 Demo 88%（差 1 局到 90%）。三幕通关新 Demo 23%（略低于 25%），瓦 Demo 25%。
- casual 到达第一幕 Boss：新 Demo 13% → 55%，瓦 Demo 23% → 60%。casual 第一幕通关仍低（新 Demo 20%），死因主要是第一幕 Boss 与 9 层以后的突破手／架枪组；Boss 仍保持挑战。
- naive 几乎不变：它按手牌顺序乱打（新 Demo 连姿态都不用），前哨侦察兵会因它乱打技能牌而不断变强。它只是下限，不代表真人。
- 队伍／赛区差距仍在：新 Demo 烈锋突击队普通战失血最高；瓦版中国赛区三幕通关最低。
- 以上都是机器人数据，结论仍需真人试玩确认；这次只动了对手数值，没有改卡牌。
