# 瓦demo PvP 规则与快照模块

## 快照 (Snapshot)

- 爬塔（赛季模式）在以下几个时点生成 PvP 快照：
  - 第一、二幕击败 Boss 后，完成奖励选择（包括跳过皮肤）进入休整期（intermission）时。
  - 第三幕冠军战胜利后（phase='result', outcome='win'）。
- 快照内容：`{ id, runId, act, version:'wa-pvp-1', seed, region, deck:[{uid,id,up}], skins:[id], maxHp, hp:maxHp, money, actionsCount }`。
- 仅包含永久构筑（选手牌与 CU 诅咒），不包含临时牌、战斗日志、手牌、弃牌堆、消耗区等。
- 快照生成前会将玩家当前生命值回满至最大生命值。
- 每 (runId, act) 仅保留一份快照，重复生成不会覆盖既有快照。

## 成长选项：坚韧 (toughness)

- 在俱乐部活动（activity）阶段新增“坚韧”选项：消耗本次休整机会，使最大生命值和当前生命值各 +6。
- 该动作记录到 actions，rev+1，并推进到地图阶段。

## PvP 对战规则

### 开局

- 双方必须使用同一幕（act）和同一竞技规则版本（wa-pvp-1）的快照。
- 双方各自以快照中的最大生命值满血开局，不进行归一化。
- 初始手牌为空。每名玩家在自己的第一个回合开始时抽 5 张牌（可能因能力 extraDraw 增加）。
- 先手由服务器私有种子决定。

### 回合结构

- 全场采用整回合交替：一名玩家完成其回合后，轮换至另一名玩家。
- 回合开始：
  - 清空该玩家自己的布防（block=0）。
  - 行动点（energy）重置为基础 3 点，加上能力加成（energy）。
  - 重置 roleCounts。
  - 若这是该玩家本场第一个回合且拥有皮肤 SK01，获得 3 点布防。
  - 抽 5 张牌，加上能力 extraDraw。
- 回合结束：
  - 手中若有 CU02，每张直接失去 2 点生命值（无视布防）。
  - 剩余手牌按卡牌 zone 属性进入弃牌堆或消耗区（exhaust/临时/回合末消耗）。
  - 该玩家自己的压制（weak）和易伤（vulnerable）各减 1（最低 0）。
  - 轮换到对手。

### 状态效果

- **布防 (Block)**：抵消攻击伤害，在拥有者自己回合开始时清空。
- **压制 (Weak)**：攻击伤害降低 25%（向下取整），在拥有者自己回合结束时减 1。
- **易伤 (Vulnerable)**：受到攻击伤害增加 50%（向下取整），在拥有者自己回合结束时减 1。

### 卡牌效果

- 伤害：攻击玩家，先扣除布防，再扣生命。伤害计算为基础值经过压制/易伤调整后取整。每次攻击单独结算。
- 布防：施放者获得布防。
- 压制/易伤：施加给对手，增加对应持续回合数。
- 抽牌：抽指定数量的牌。抽牌时若牌堆空且弃牌堆有牌，将弃牌堆洗入牌堆（消耗区除外）。手牌上限 10。
- 临时牌（token）：生成 0 费临时牌加入手牌，若手牌已满则不生成。临时牌在回合结束或打出后进入消耗区。
- 能力牌（power）：打出后进入能力区，持续整场，效果叠加。
- 消耗：打出后进入消耗区，本场不再洗回。
- CU02 在回合结束仍在手牌时触发扣血。

### 皮肤效果

- SK01：本场第一次自己的回合开始时获得 3 布防。
- SK02：本场第一次打出 0 费选手牌后抽 1 张牌。触发在卡牌进入弃牌堆之前。
- SK03：每回合第一次打出哨位牌后获得 2 布防。

### 胜负

- 攻击使对手生命值降至 0 或以下时，攻击方立即获胜，停止后续效果。
- 玩家可认输（concede），对手获胜。
- 达到 200 个玩家回合仍未分胜负，判定平局（winner=null）。

### 隐私

- 每个玩家仅能看到自己的手牌内容和自己的抽牌堆数量；对手只能看到手牌数量和抽牌堆数量。
- 弃牌堆、消耗区、能力区对双方公开（卡牌 ID 与升级状态）。
- 公共日志不包含抽到的具体卡牌名称，仅记录抽牌数量。
