# 新demo完整规则

## 语义
- 玩家指挥一支稳定队伍，卡牌表示战术行动。牌为突破、架点、烟闪、补枪、回防等。
- 敌方为敌队，有明确意图，装备仅文字，非武器怪物。
- 血量表示队伍状态，战斗失败队伍出局。

## 卡池与获得
- 75张独立永久行动卡（`CARD_IDS`精确75），含普通/罕见/稀有。
- 奖励从完整75池按稀有度权重随机，不重复，允许跳过。
- 商店可购卡/删牌。
- 4套初始牌组：突破、架点、道具协同、调度；不含状态卡。3 种独立负面状态牌（ST01失误/ST02犹豫/ST03暴露）由敌人施加且不可打出。烟/闪为状态数值，不是卡牌。

## 战斗规则
- 每回合3能量，抽5张，手牌上限10。
- 出牌后进入弃牌堆，消耗卡进入消耗堆本场不可再用。
- 能力卡本场持续。
- 每回合最多出牌40次防止无限。
- 死亡即结束。

## 姿态机制：掩护/前压
- 初始为掩护。
- 每回合第一次手动切换消耗1能量（无卡牌要求），之后本回合不能再手动切。
- 卡牌切换姿态支付该卡自身费用，不消耗手动切换次数，不重置首次奖励。
- 掩护：每回合第一次布防+3。
- 前压：每回合第一次攻击+3，但敌人每次对你造成的攻击额外+2伤害。
- 奖励只对第一次攻击/布防生效，切换不刷新。

## 状态效果
- 烟雾：敌方每次攻击伤害减少 n（n为烟雾层数），敌方回合结束时烟雾层数-1。
- 闪光：敌方下一次攻击伤害额外减少 3n（n为闪光层数），并消耗所有闪光。

## 战役流程
- 三幕，每幕11层分叉连通地图。
- 普通/精英/boss战、事件、商店、休整。
- 战斗胜利3选1奖励，boss额外遗物。
- 幕间回满血并保留构筑。
- 三幕boss胜利最终胜利。

## 随机与种子
- 同一种子地图、洗牌、奖励完全一致。
- 使用xorshift，非法动作不消耗随机且不改变状态。
