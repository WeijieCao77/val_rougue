# 新 Demo 首幕试玩记录与调整（2026-09-23）

这一轮按交接建议先做首幕试玩，再用数据调整卡牌和对手。试玩由脚本驱动真实引擎（`new-demo/engine.js` 的 `legalActions/act`），不是真人试玩。结论仍需要你亲自试玩验证。

## 方法

`tools/playtest-new-demo.mjs` 对四支队伍各跑 10 个固定种子，用三种打法对照：

- **细心打法（smart）**：每回合枚举本回合所有可行出牌顺序（含切姿态），按“敌方意图结算后”的局面打分，选最好的一条。它会看到抽牌堆顺序，比真人略占便宜。路线：血量高时打强敌，低时去休整；奖励只拿比当前卡组平均更好的牌。
- **随手打法（naive）**：按手牌顺序能出就出，从不切姿态。
- **随机打法（random）**：随机出牌、随机路线。

每回合记录：能否一口气打完整手牌、细心打法比随手打法好多少（`gap`）、是否用了姿态、哪些牌被留在手里、掉了多少血。`tools/playtest-summary.mjs` 按对手汇总。原始记录写在被 Git 忽略的 `reports/playtest/`。

## 改动前发现的问题

| 问题 | 数据 | 为什么影响乐趣 |
| --- | --- | --- |
| 普通战太轻松 | 细心打法每场普通战平均只掉 **0.1–1.3** 血，2.5 回合结束 | 普通战没有代价，就不需要构筑，也没有路线取舍 |
| 敌人不会成长 | 对手只循环三个固定动作，Boss 也不会越打越强 | 不需要速攻或成长型牌，高费牌和能力牌缺少用处 |
| 高费牌不划算 | 按粗略估值，2 费牌平均只有 1 费牌的 1.3–1.5 倍，稀有 2 费甚至只有稀有 1 费的 1.1 倍 | 抽到高费牌时不如打两张低费牌，高费决策就没有意义 |
| 太平洋·调度起手牌有无限循环 | 0 费抽牌（快速换弹、战术雷达）配 0 费攻击，一回合最多连出 **40 张**（引擎上限），96/214 回合出牌 ≥8 张 | 第一场就能无代价地一回合打穿对手 |
| 卡牌奖励常被跳过 | 细心打法跳过约 37% 的奖励 | 奖励牌普遍不如起手牌，成长感弱 |
| 打法差异大 | 随手打法首幕通关 0–9/10，细心打法 10/10 | 好消息是出牌选择确实重要；问题是细心之后就没有压力 |

## 这一轮改动

1. **敌人火力成长**：新增敌方意图 `buff`（强化火力），本场之后每次命中伤害 +层数。对手面板显示“火力”状态；如果同一回合先强化再攻击，意图里的攻击数字已经算上这次强化。普通对手、强敌和三幕 Boss 都加了成长动作。
2. **对手数值**：首幕普通对手 HP 40–52 → 50–60，单次伤害约 +2～3；首幕强敌 72 → 90 HP；首幕 Boss 110 → 130 HP，并加入强化回合。第二、三幕原来比第一幕还轻松（第二幕强敌平均只掉 1.9 血），现在按比例提高：第二幕强敌 118 HP、Boss 180 HP；第三幕强敌 140 HP、Boss 245 HP。
3. **高费牌加强**：所有 2 费非能力牌的伤害、布防、治疗 ×1.35，3 费 ×1.3（四舍五入；共享牌 15 张、赛区牌 80 张）。抽牌、能量、烟闪、压制、易伤数值不变。例如正面突击 8→11、扫射压制 5×3→7×3、致命补枪 16(+10)→21(+13)。
4. **起手牌**：
   - 太平洋·调度：快速换弹、战术观察、紧急调度换成穿墙射击、基础架点、战术换防，去掉起手无限循环，保留抽牌和姿态节奏。
   - 美洲·突破：一张基础补枪换成破片手雷（易伤，符合“易伤联动”），战术观察换成第二张基础架点。
   - EMEA·道具：基础闪光换成基础架点，降低开局烟闪减伤的叠加。
5. **引擎**：出牌数达到每回合上限后，`legalActions` 不再列出出牌动作。

## 仍未解决

- **队伍强弱**：三幕全通关，EMEA·道具 7/8、中国·架点 4/8、美洲·突破 3/8、太平洋·调度 2/8。烟闪减伤（闪光每层抵 3 点）明显最强；样本小，需要真人试玩确认后再动烟闪规则。
- **普通战仍偏快**：细心打法 3 回合左右结束。机器人知道抽牌顺序，真人会更吃力，先看你的手感再决定是否继续加压。
- **奖励牌仍常被跳过**：估值函数很粗，不能据此判断卡牌强弱。
- 自动试玩只证明规则与数值走势，不证明“好玩”。请重点感受：普通战是否需要取舍，强敌是否值得冒险，高费牌是否愿意拿。

复现：`node tools/playtest-new-demo.mjs --seeds 10 --acts 1`，全程加 `--acts 3`；汇总 `node tools/playtest-summary.mjs reports/playtest/<文件>.json`。
