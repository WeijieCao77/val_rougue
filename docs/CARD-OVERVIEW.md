# 两个 Demo 的卡牌总览

开局页统一提供“卡牌总览”，阅读不启动新局、不写存档，也不改变已输入种子。

- 瓦demo：默认79张卡；分类为72张选手牌、3张比赛干扰、2张俱乐部隐患、2张临时行动，另列3件皮肤遗物。选手牌可查看全部或按四赛区筛选。原卡框、图片、训练后效果和参考来源保留。
- 新demo：75张战术牌、3张状态牌、12件遗物分开显示。战术牌保留类型、标签、费用筛选及可展开升级文本；状态牌不算入75张永久卡池。遗物说明其被动效果。
- 使用游戏原始数据动态生成卡库及计数，没有增加或调整卡牌数值。
- 本地桌面1440和手机390宽度均通过真实浏览器验收：分类计数、四赛区与全部切换、空筛选恢复、升级说明、关闭与重新打开、无横向溢出；localStorage和开局种子未改变，无页面脚本错误。
- 构建通过；109项回归测试通过。主实现及返修来自DeepSeek v4-pro，主代理审核集成与浏览器验收。
